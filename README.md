# 需求前置分析平台

业务部门提交需求 → **AI 前置澄清**把需求聊清楚（顾问式对话，AI 自主判断需求形态与还缺什么，表1/表2 仅作内部 checklist）→ 自动生成结构化**需求画像** → 输出**三档方案**（初级=快速判断；中级=可评审方案；高级=完整立项；三档每档均含**产品版 + 技术版**，共 6 份）→ 全流程**进度反馈** + **AI 价值优先级分析**（P0/P1/P2）。

## 快速开始

```bash
cd /Users/laya/Desktop/需求前置分析网站
node server.js
```

浏览器打开 **http://localhost:3210** （可用环境变量改端口：`PORT=8080 node server.js`）

零依赖、无需安装任何 npm 包（Node ≥ 18）。

## 功能地图

| 你的需求 | 平台实现 |
| --- | --- |
| 给业务部门提需求的网站 | 「新建需求」表单 + 工作台需求列表 |
| AI 前置聊清楚 | AI 澄清对话：判断需求本质（单点决策/SOP流程），按《表1》《表2》框架一次一问，边聊边提取结构化画像，支持一次回答多条信息 |

## 页面

- **工作台** `#/dashboard` — 统计、需求列表、进度、优先级
- **新建需求 · AI澄清** `#/new` — 提交表单 → 与 AI 对话澄清 → 实时画像面板 → 生成三档方案
- **需求详情** `#/req/:id` — 三档方案（含文档查看/下载）、需求画像、价值分析、进度时间线
- **价值优先级** `#/priority` — 全局排序看板与评分模型
- **设置** `#/settings` — AI 引擎切换、大模型配置、数据管理
- **知识库挂载** `#/settings` — 本地目录 / RAGFlow / 通用 HTTP Provider（默认关闭）

## AI 能力来源（三种模式，可随时切换）

1. **内置 AI 引擎**（默认，零配置）：基于表1/表2 框架的规则引擎 —— 结构化提问、字段提取、模板化方案生成与价值打分，完全离线可用。
2. **混合模式（大模型 API 开启后自动生效）**：规则状态机仍是骨架（确定性、可终止、可兜底），LLM 获得"自主性"：
   - **LLM 自主追问**：每轮由 LLM 根据当前画像自主决定问什么（规则引擎把仍缺失的标准字段作为参考传入），可追问画像外但影响方案的关键点（合规、边界、口径、上线窗口等）；
   - **规则校验画像**：每轮回答仍由规则引擎确定性提取，画像结构与内置模式完全一致；
   - **交付前自检**：标准字段齐后，LLM 对照框架审查画像，自动追问关键缺口（最多 5 个，可跳过），答完才出最终确认；
   - **失败自动回退**：未配置 Key / 调用失败 / 超时 → 自动降级为内置引擎，流程不中断。
3. **大模型 API**：OpenAI 兼容接口（DeepSeek / OpenAI / 通义千问 / Kimi 均可），在「设置」中配置。

> 测试混合模式无需真实 Key：`node scripts/mock_llm.js` 起一个本地 mock 接口，把设置里 baseUrl 指向 `http://127.0.0.1:3999` 即可。

## 数据

- 数据落盘在 `data/db.json`（首次启动自动载入两条完整示例：滞销SKU处置判断 / 商品优化建议SOP）。
- 设置页可「清空全部数据」或「恢复示例数据」。

## 知识库挂载

平台支持可插拔知识库上下文层，默认关闭，不影响零依赖主流程：

- `local`：挂载本地 Markdown / TXT / JSON / CSV / YAML 目录，适合开发和小规模试点；
- `ragflow`：调用 RAGFlow `/api/v1/retrieval`；
- `http`：调用公司自建的通用 `POST` JSON 检索服务。

启用后，知识库结果只作为 AI 澄清、自检和方案生成的背景上下文；检索失败不会阻断流程，价值评分仍由确定性规则引擎完成。配置入口在「设置 → 知识库挂载」。

通用 HTTP Provider 请求体约定：

```json
{ "query": "需求方案", "topK": 5, "datasetId": "optional" }
```

返回值可使用 `results`、`chunks`、`records` 或 `items` 数组，片段字段支持 `text` / `content`，来源字段支持 `source` / `title` / `document_name`。

```
lib/knowledge/
  index.js             可插拔 Provider 与统一检索上下文层
    value.js           价值优先级评分 + 项目级评估（规模/风险/人月/置信度）

  index.html / css/ / js/
```

## 与「析需 ReqPilot」（同事 demo）的定位差异

本平台 = **对话式需求澄清**（业务直接说，AI 按表1/表2 框架聊清楚）+ **零依赖开箱即用**（内置引擎离线可跑，大模型可选）+ **跨需求价值排序**；同事的 ReqPilot = **需求文件上传** + 纯 LLM + RAGFlow 知识库 + Word 交付。本平台已吸收其优点：Word(.docx) 导出、项目级规模/风险/人月评估、skills 式文档生成规则。
